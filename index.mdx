Celesto gives each AI agent its own computer. Your agent can run code, browse the web, and save its work, safely separated from your app and your machine. You can stop a computer and pick up where it left off later.

Celesto also runs your GitHub Actions jobs, so your builds and tests run faster and cost less.

## Hosted or open source

Use Celesto Cloud when you want managed computers. Use the open-source [Celesto](/celesto/introduction) runtime when you want to run everything on your own machine. See [hosted and open source](/getting-started/hosted-and-open-source) to compare them.
