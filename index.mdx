## GitHub Actions

- [Runner sizes](/ci/runner-sizes): 1–8 vCPUs, 2–32 GB RAM, Ubuntu 24.04 (Linux x64).
- [Cache](/ci/caching): Reuse [dependencies](/ci/caching), [Turbo results](/ci/turbo-cache), and [Docker layers](/ci/docker-cache).
- [CLI](/ci/cli): Check jobs with `celesto ci jobs list`.
- [Security](/ci/security): Fresh, isolated computers with runners registered per job.

## Sandboxes

- [MicroVMs](/cloud/overview): Run code in lightweight, isolated virtual machines.
- [Open source](/celesto/introduction): Run Celesto sandboxes on your own machine.
