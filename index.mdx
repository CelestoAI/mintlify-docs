## Quick Example

Build an AI agent with tool access in just a few lines:

```python
from agentor import Agent

agent = Agent(
    name="research_assistant",
    model="gpt-4",
    tools=["web_search"]
)

# Run agent with natural language
result = agent.run("Find the latest AI research papers on arxiv")
print(result)
```

<Tip>
Check out our [Quickstart Guide](/agentor/overview) to build your first agent in minutes.
</Tip>
