## Build without outgrowing the sandbox

Create a 10 GB sandbox and write a 20 GB file in the sandbox home directory. In Celesto Linux sandboxes, `/home/ohm` is that home directory. The root disk stays small while the CelestoFS workspace handles large agent data.

```bash CLI
celesto computer create --template coding-agent --disk-size-mb 10240

celesto computer run einstein "python3 - <<'PY'
from pathlib import Path

target = Path('/home/ohm/storage-proof/twenty-gib.bin')
target.parent.mkdir(parents=True, exist_ok=True)

with target.open('wb') as f:
    chunk = (b'celesto-storage-proof\n' * 65536)[:1024 * 1024]
    for gib in range(20):
        for _ in range(1024):
            f.write(chunk)
        f.flush()
        print(f'wrote {gib + 1} GiB', flush=True)

print(target.stat().st_size)
PY"

celesto computer run einstein "du -h /home/ohm/storage-proof/twenty-gib.bin && df -h / /home/ohm"
```

Example `df -h` output:

```text
Filesystem      Size  Used Avail Use% Mounted on
/dev/root        10G  2.2G  7.8G  22% /
celestofs       1.0P  161M  1.0P   1% /home/ohm
```
