Run builds and tests on Celesto. Each job gets a fresh computer; results and logs stay in GitHub Actions.

## Quickstart

You need admin access to your GitHub repository and Celesto workspace, plus workspace credit. Workspace owners can start an eligible $5 Micro trial.

<Steps>
  <Step title="Connect your repository">
    [Install the Celesto CI GitHub App](https://github.com/apps/celesto-ci/installations/new), select your repositories, and follow the redirect to connect a Celesto workspace. Start the trial or add credit to finish setup.
  </Step>
  <Step title="Add a workflow">
    Save as `.github/workflows/celesto-ci.yml`:

    ```yaml .github/workflows/celesto-ci.yml
    name: Celesto CI
    on: [push, workflow_dispatch]
    jobs:
      verify:
        runs-on: celesto-micro
        timeout-minutes: 90
        steps:
          - uses: actions/checkout@v4
          - name: Check the runner
            run: |
              uname -m
              python --version
              node --version
              git --version
              echo "Running on Celesto"
    ```

    For an existing workflow, change `runs-on` and keep your steps.

    <Note>
      Micro has 1 vCPU and 2 GB RAM. When migrating, [match your current runner's CPU and memory](/ci/runner-sizes#match-your-current-runner).
    </Note>
  </Step>
  <Step title="Push and check the result">
    Push the workflow and open **Actions → Celesto CI** in GitHub. Expect `x86_64`, tool versions, `Running on Celesto`, and a green check.
  </Step>
</Steps>

## Sizes and prices

Use one label in `runs-on`. The bare `celesto` label selects Micro. All sizes run Ubuntu 24.04 Linux x64. USD rates below are rounded; your workspace billing catalog has current rates.

| Size | Workflow label | vCPU | RAM | Disk | Per minute | Per hour |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| Micro | `celesto-micro` | 1 | 2 GB | 20 GB | $0.00025 | $0.015 |
| Small | `celesto-small` | 1 | 4 GB | 25 GB | $0.00033333 | $0.020 |
| Standard | `celesto-standard` | 2 | 4 GB | 30 GB | $0.0005 | $0.030 |
| Memory | `celesto-memory` | 2 | 8 GB | 40 GB | $0.00066667 | $0.040 |
| Large | `celesto-large` | 4 | 16 GB | 60 GB | $0.00133333 | $0.080 |
| XL | `celesto-xl` | 8 | 32 GB | 100 GB | $0.00266667 | $0.160 |

Billing covers preparation, execution, and cleanup. The one-time $5 trial covers up to 20,000 Micro runtime minutes, expires after 30 days, and is shared with sandbox usage. Other sizes need eligible credit; some promotions cover only Micro or Small.

## Choose the right size

For 2 vCPU and 8 GB RAM, use `celesto-memory`. See [runner sizes](/ci/runner-sizes) to match GitHub or Blacksmith runners.

Install project dependencies and additional tools in your workflow. Pin versions with setup actions such as `actions/setup-node` or `actions/setup-python`.

## Limits and compatibility

- **Platform:** Linux x64. See [Docker builds and services](/ci/docker) for container support.
- **Runtime:** Two-hour safety limit. Keep `timeout-minutes` below 120 to allow preparation and cleanup.
- **Concurrency:** Depends on capacity, workspace limits, and credit. The trial allows one retained computer.
- **Files:** Computers are deleted after each job. Save results as artifacts and reuse dependencies with [caching](/ci/caching).
- **Access:** Select every repository using Celesto in the GitHub App. See [security and permissions](/ci/security).
- **Labels:** Use exactly one Celesto size label.
- **Network:** Jobs need outbound access to GitHub and your workflow's services.

## If a job stays queued

Open the **Celesto runner setup** check for setup, permission, or credit errors. After fixing the issue, cancel the blocked run and rerun it. See [troubleshooting](/ci/troubleshooting) for recovery steps.
