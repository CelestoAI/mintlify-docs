Agentor handles the complexity of [tool calling](./overview) for you. You write a regular Python function, add a decorator, and Agentor takes care of generating the tool schema, parsing the LLM's response, and calling your function with the right arguments.

## Function tools

The quickest way to create a tool is the `@function_tool` decorator. It turns any Python function into a tool that agents can use:

```python  theme={null}
from agentor import Agentor, function_tool

@function_tool
def get_weather(city: str) -> str:
    """Get the weather of a city"""
    return f"Weather in {city} is sunny"

agent = Agentor(name="Weather Agent", tools=[get_weather])
result = agent.run("What is the weather in London?")
print(result)
```

```markdown
RunResult:
- Last agent: Agent(name="Weather Agent", ...)
- Final output (str):
    London weather: sunny right now. Would you like the temperature or a short forecast?
```

The `@function_tool` decorator reads your function's name, docstring, and type hints to automatically generate the tool schema the LLM needs. This means:

- The **function name** becomes the tool name
- The **docstring** becomes the tool description (the LLM reads this to decide when to use the tool)
- **Type hints** define the parameter schema

## The @tool decorator

The `@tool` decorator creates a dual-mode tool that works with both Agentor agents and the lower-level `LLM` client:

```python  theme={null}
from agentor import Agentor, tool

@tool
def search_contacts(name: str, limit: int = 5) -> str:
    """Search for contacts by name."""
    return f"Found {limit} contacts matching '{name}'"

agent = Agentor(name="Contact Agent", tools=[search_contacts])
result = agent.run("Find contacts named Alice")
```

You can customize the tool name and description:

```python  theme={null}
@tool(name="contact_lookup", description="Look up contacts in the CRM system")
def search_contacts(name: str) -> str:
    """Search for contacts by name."""
    return f"Found contacts matching '{name}'"
```

## Multi-capability tools

For tools with multiple related operations, use the `BaseTool` class with the `@capability` decorator:

```python  theme={null}
from agentor.tools.base import BaseTool, capability

class NotesTool(BaseTool):
    name = "notes"
    description = "Create and search notes"

    def __init__(self):
        super().__init__()
        self.notes = []

    @capability
    def add_note(self, title: str, content: str) -> str:
        """Add a new note."""
        self.notes.append({"title": title, "content": content})
        return f"Note '{title}' saved"

    @capability
    def search_notes(self, query: str) -> str:
        """Search notes by keyword."""
        matches = [n for n in self.notes if query.lower() in n["title"].lower()]
        return str(matches) if matches else "No notes found"
```

Each `@capability` method becomes a separate tool the agent can call.

## Built-in tools

Agentor includes pre-built tools for common tasks. You can reference them by name or instantiate them directly:

```python  theme={null}
from agentor import Agentor
from agentor.tools import CalculatorTool, GetWeatherTool, ShellTool

# Instantiate and pass to the agent
agent = Agentor(
    name="Multi-Tool Agent",
    model="gpt-4o-mini",
    tools=[CalculatorTool(), ShellTool()]
)
```

The full list of built-in tools:

| Tool | Description | Requires |
|------|-------------|----------|
| `CalculatorTool` | Arithmetic operations | - |
| `GetWeatherTool` | Weather data | `WEATHER_API_KEY` |
| `WebSearchTool` | Web search | - |
| `ExaSearchTool` | Neural web search | `pip install agentor[exa]` |
| `FetchTool` | HTTP requests | - |
| `GitTool` | Git operations | `pip install agentor[git]` |
| `GitHubTool` | GitHub API | `pip install agentor[github]` |
| `GmailTool` | Gmail access | Google OAuth credentials |
| `ShellTool` | Shell commands | - |
| `SlackTool` | Slack messaging | `pip install agentor[slack]` |
| `PostgreSQLTool` | Database queries | `pip install agentor[postgres]` |
| `ScrapeGraphAI` | AI web scraping | `pip install agentor[scrapegraph]` |
| `LinkedInScraperTool` | LinkedIn profiles | `BRIGHT_DATA_API_KEY` |
| `TimezoneTool` | Timezone lookups | - |
