**Agentor** is an open-source framework that makes it easy to build multi-agent systems, MCP Servers or ANY LLM application with secure integrations across email, calendars, CRMs, and more.


## Start with four steps

<Steps>
<Step title="Install">

```bash
pip install agentor
```
</Step>


<Step title="Build an Agent">

Once installed, you can start building your first Agent with just a few lines of code.

```python
from agentor import Agentor

agent = Agentor(
    name="Weather Agent",
    tools=["get_weather"],  # 100+ Celesto AI managed tools — plug-and-play
)
result = agent.run("What is the weather in London?")
```
</Step>


<Step title="Run the Agent as a server">

Agents can be run as a server to be integrated into other applications such as UI applications, or other LLM applications.

```python
from agentor import Agentor

agent = Agentor(name="Weather Agent", tools=["get_weather"])
agent.serve() # Single line of code to serve the Agent [!code ++]
```

<Tip>Deploy your Agent to [cloud](https://celesto.ai) with a single command: `agentor deploy`</Tip>

</Step>

<Step title="Query the Agent server">

You can query your Agent server with a simple curl command.

<CodeGroup>
```bash cURL
curl -X 'POST' \
  'http://localhost:8000/chat' \
  -H 'accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
  "input": "What is the weather in London?"
}'
```

```python Python Requests
import requests

response = requests.post(
    "http://localhost:8000/chat",
    json={"input": "What is the weather in London?"},
    headers={"Content-Type": "application/json"}
)
print(response.content)
```

```python Cloud
import os
import requests

URL = "https://api.celesto.ai/v1/deploy/apps/APP-ID/chat"
CELESTO_API_KEY = os.environ.get("CELESTO_API_KEY")

headers = {
    "Authorization": f"Bearer {CELESTO_API_KEY}",
    "Content-Type": "application/json",
}

response = requests.post(
    URL,
    json={"input": "how are you?"},
    headers=headers,
)
print(response.content)
```
</CodeGroup>

</Step>
