**Agentor** is an open-source framework that makes it easy to build multi-agent systems with secure integrations across email, calendars, CRMs, and more.


## Usage

<Steps>
<Step>
### Installation

Recommended

```bash
pip install agentor
```

Latest (unstable)

```bash
pip install git+https://github.com/celestoai/agentor@main
```
</Step>
<Step>
Once installed, you can start building your first Agent with just a few lines of code.

```python
from agentor import Agentor, function_tool

agent = Agentor(
    name="Weather Agent",
    tools=["get_weather"],  # 100+ Celesto AI managed tools — plug-and-play
)

result = agent.run("What is the weather in London?")
print(result)

# Serve Agent with a single line of code
agent.serve()
```
</Step>

<Step>
You can serve your Agents locally or on cloud with a single command. 

```bash
agentor deploy
```
</Step>

</Steps>

## Security & Privacy

### Your data stays yours

- **Local credentials** — Stored securely on your machine
- **No data collection** — We never see your emails or calendar
- **Open source** — Audit the code yourself
- **Standard OAuth** — Uses Google’s official authentication

### Credential management

- Automatic token refresh
- Secure local storage
- Per-user isolation
- Configurable credential paths
