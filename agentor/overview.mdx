**Agentor** is an open-source framework that makes it easy to build multi-agent systems with secure integrations across email, calendars, CRMs, and more.


## Usage

<Steps>
<Step title="Install">

Recommended

```bash
pip install agentor
```

Latest (unstable)

```bash
pip install git+https://github.com/celestoai/agentor@main
```
</Step>

<Step title="Build an Agent">

Once installed, you can start building your first Agent with just a few lines of code.

```python
from agentor import Agentor, function_tool

agent = Agentor(
    name="Weather Agent",
    tools=["get_weather"],  # 100+ Celesto AI managed tools — plug-and-play
)

result = agent.run("What is the weather in London?")
print(result)

# Serve Agent with a single line of code
agent.serve()
```
</Step>

<Step title="Serve an Agent">

You can serve your Agents locally or on cloud with a single command. 

```bash
agentor deploy
```
</Step>

<Step title="Query the Agent server">

You can query your Agent server with a simple curl command.

<CodeGroup>
```python Local Deployment
import requests

URL = "http://localhost:8000/chat"

response = requests.post(
    URL,
    json={"input": "how are you?"},
    headers={"Content-Type": "application/json"}
)
print(response.content)
```

```python Cloud Deployment
import os
import requests

URL = "https://api.celesto.ai/v1/deploy/apps/APP-ID/chat"
CELESTO_API_KEY = os.environ.get("CELESTO_API_KEY")

headers = {
    "Authorization": f"Bearer {CELESTO_API_KEY}",
    "Content-Type": "application/json",
}

response = requests.post(
    URL,
    json={"input": "how are you?"},
    headers=headers,
)
print(response.content)
```

```bash cURL
curl -X 'POST' \
  'http://localhost:8000/chat' \
  -H 'accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
  "input": "What is the weather in London?"
}'
```
</CodeGroup>

</Step>

</Steps>

## Security & Privacy

### Your data stays yours

- **Local credentials** — Stored securely on your machine
- **No data collection** — We never see your emails or calendar
- **Open source** — Audit the code yourself
- **Standard OAuth** — Uses Google’s official authentication

### Credential management

- Automatic token refresh
- Secure local storage
- Per-user isolation
- Configurable credential paths
