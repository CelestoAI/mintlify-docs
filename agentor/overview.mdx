**Agentor** is an open-source framework that makes it easy to build agentic systems with secure integrations across email, calendars, CRMs, and more.


## Start with two steps

<Steps>
  <Step title="Install">
    ```bash
    pip install agentor
    ```
  </Step>
  <Step title="Build an Agent">
    Once installed, you can start building your first Agent with just a few lines of code.

    ```python
    from agentor import Agentor
    
    agent = Agentor(
        name="Spanish to English Translator Agent",
        instructions="You are a helpful assistant that translates Spanish to English.",
        model="gpt-5-mini",
    )
    result = agent.run("Hola, ¿cómo estás?")
    ```

    <Accordion title="View expected output" icon="eye">
      ```markdown
      Hello, how are you?
      ```
    </Accordion>
  </Step>

  <Step title="Add a tool capability">
    You can add tools to your Agent to perform tasks and get information from the world.

    The following example shows an Agent that can access the realtime weather information from the world.

    ```python
    from agentor.tools import WeatherAPI
    from agentor import Agentor
    
    agent = Agentor(
        name="Weather Agent",
        model="gpt-5-mini",
        tools=[WeatherAPI()]
    )
    result = agent.run("What is the weather in London?")
    ```
  </Step>

</Steps>
