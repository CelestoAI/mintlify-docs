**Agentor** is an open-source framework that makes it easy to build multi-agent systems with secure integrations across email, calendars, CRMs, and more.


## Usage

<Steps>
<Step>
### Installation

Recommended

```bash
pip install agentor
```

Latest (unstable)

```bash
pip install git+https://github.com/celestoai/agentor@main
```
</Step>
<Step>
Once installed, you can start building your first Agent with just a few lines of code.

```python
from agentor import Agentor, function_tool

agent = Agentor(
    name="Weather Agent",
    tools=["get_weather"],  # 100+ Celesto AI managed tools — plug-and-play
)

result = agent.run("What is the weather in London?")
print(result)

# Serve Agent with a single line of code
agent.serve()
```
</Step>

<Step>
You can serve your Agents locally or on cloud with a single command. 

```bash
agentor deploy
```
</Step>

</Steps>



## Agents API

Integrate Agentor directly into your applications with just a few lines of code:

<CodeGroup>
```python With Celesto AI ToolHub
from agentor import Agentor

agent = Agentor(
    name="Weather Agent",
    model="gpt-5-mini",
    tools=["get_weather"],  # 100+ Celesto AI managed tools — plug-and-play
)
result = agent.run("What is the weather in London?")
print(result)
```

```python Bring your own tool
from agentor import Agentor, function_tool

@function_tool
def get_weather(city: str):
    """Get the weather of city"""
    return f"Weather in {city} is sunny"

agent = Agentor(
    name="Weather Agent",
    model="gpt-5-mini",
    tools=[get_weather],  # Bring your own tool
)
result = agent.run("What is the weather in London?")
print(result)
```

</CodeGroup>

To query your Agent server:

```bash
curl -X 'POST' \
  'http://localhost:8000/chat' \
  -H 'accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
  "input": "What is the weather in London?"
}'
```

## Features

| Feature                    | Description                                                                                               |
| -------------------------- | --------------------------------------------------------------------------------------------------------- |
| ✅ **Pre-built Agents**     | Ready-to-use tools                                                                                        |
| 🔐 **Secure Integrations** | Email, calendar, CRMs, and more                                                                           |
| 🦾 **AgentMCP**            | [Code](https://github.com/CelestoAI/agentor/tree/main/docs/tools-and-mcp.mdx)                             |
| ☁️ **Easy Deployment**     | [`agentor deploy FOLDER_PATH`](https://github.com/CelestoAI/agentor/tree/main/docs/examples/agent-server) |


```python
from agentor import CelestoSDK

client = CelestoSDK(CELESTOAI_API_KEY)

# List all available tools
client.toolhub.list_tools()

# Run the weather tool
client.toolhub.run_weather_tool("London")

# Run the Google email tool
client.toolhub.run_list_google_emails(limit=5)
```

## Tool Routing with AgentMCP

When multiple tools are added directly to an Agent, LLM context can bloat and degrade performance.

`AgentMCP` solves this by exposing one unified interface that automatically routes calls to the correct tool — optimizing performance and context efficiency.

## Security & Privacy

### Your data stays yours

- **Local credentials** — Stored securely on your machine
- **No data collection** — We never see your emails or calendar
- **Open source** — Audit the code yourself
- **Standard OAuth** — Uses Google’s official authentication

### Credential management

- Automatic token refresh
- Secure local storage
- Per-user isolation
- Configurable credential paths
