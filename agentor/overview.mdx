**Agentor** is an open-source framework that makes it easy to build AI Agents, distributed multi-agent systems, MCP Servers or ANY LLM application with secure integrations across email, calendars, CRMs, and more.

## Start with four steps

<Steps>
  <Step title="Install">
    ```bash
    pip install agentor
    ```

    <Info>
      You'll need an API key from your LLM provider (OpenAI, Anthropic, etc.). Set it as an environment variable:

      ```bash
      export OPENAI_API_KEY="your-api-key-here"
      ```
    </Info>
  </Step>
  <Step title="Build an Agent">
    Once installed, you can start building your first Agent with just a few lines of code.

```python
from agentor.tools import WeatherAPI
from agentor import Agentor

agent = Agentor(
    name="Weather Agent",
    tools=[WeatherAPI()]
)
result = agent.run("What is the weather in London?")
```

    <Accordion title="View expected output" icon="eye">
      ```json
      {
        "response": "The current weather in London is 15°C with partly cloudy skies. Wind speed is 12 km/h from the northwest."
      }
      ```
    </Accordion>
  </Step>
  <Step title="Run the Agent as a server">
    Agents can be run as a server to be integrated into other applications such as UI applications, or other LLM applications.

    ```python
    from agentor.tools import WeatherAPI
    from agentor import Agentor
      
    agent = Agentor(name="Weather Agent", tools=[WeatherAPI()])
    agent.serve() # Single line of code to serve the Agent [!code ++]
    ```

    <Tip>
      Deploy your Agent to [cloud](https://celesto.ai) with a single command: `celesto deploy`
    </Tip>
  </Step>
  <Step title="Query the Agent server">
    You can query your Agent server with a simple curl command.

    <CodeGroup>

    ```bash cURL
    curl -X 'POST' \
      'http://localhost:8000/chat' \
      -H 'accept: application/json' \
      -H 'Content-Type: application/json' \
      -d '{
      "input": "What is the weather in London?"
    }'
    ```

    
    ```python Python Requests
    import requests
    
    response = requests.post(
        "http://localhost:8000/chat",
        json={"input": "What is the weather in London?"},
        headers={"Content-Type": "application/json"}
    )
    print(response.content)
    ```

    
    ```python Cloud
    import os
    import requests
    
    URL = "https://api.celesto.ai/v1/deploy/apps/APP-NAME/chat"
    CELESTO_API_KEY = os.environ.get("CELESTO_API_KEY")
    
    headers = {
        "Authorization": f"Bearer {CELESTO_API_KEY}",
        "Content-Type": "application/json",
    }
    
    response = requests.post(
        URL,
        json={"input": "how are you?"},
        headers=headers,
    )
    print(response.content)
    ```

    </CodeGroup>
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Agent not responding or timing out" icon="clock">
    **Common causes:**

    - Missing or invalid API key
    - Network connectivity issues
    - Rate limiting from your LLM provider

    **Solution:** Verify your API key is set correctly and check your provider's rate limits.
  </Accordion>
  <Accordion title="Tool execution errors" icon="wrench">
    **Common causes:**

    - Tool requires authentication or API keys
    - Invalid tool name or tool not available

    **Solution:** Check the [Tool Documentation](/agentor/tools/overview) for specific tool requirements.
  </Accordion>
  <Accordion title="Server won't start or port already in use" icon="server">
    **Common causes:**

    - Port 8000 is already in use by another application

    **Solution:** Specify a different port: `agent.serve(port=8001)`
  </Accordion>
  <Accordion title="Import errors or module not found" icon="code">
    **Common causes:**

    - Agentor not installed correctly
    - Using wrong Python environment

    **Solution:** Verify installation with `pip show agentor` and ensure you're using the correct Python environment.
  </Accordion>
</AccordionGroup>
