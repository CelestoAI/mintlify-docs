Integrate Agentor directly into your applications with just a few lines of code:

<CodeGroup>
```python With Celesto AI ToolHub
from agentor import Agentor

agent = Agentor(
    name="Weather Agent",
    model="gpt-5-mini",
    tools=["get_weather"],  # 100+ Celesto AI managed tools — plug-and-play
)
result = agent.run("What is the weather in London?")
print(result)
```

```python Bring your own tool
from agentor import Agentor, function_tool

@function_tool
def get_weather(city: str):
    """Get the weather of city"""
    return f"Weather in {city} is sunny"

agent = Agentor(
    name="Weather Agent",
    model="gpt-5-mini",
    tools=[get_weather],  # Bring your own tool
)
result = agent.run("What is the weather in London?")
print(result)
```

</CodeGroup>

To query your Agent server:

<CodeGroup>
```python Local Deployment
import requests

URL = "http://localhost:8000/chat"

response = requests.post(
    URL,
    json={"input": "how are you?"},
    headers={"Content-Type": "application/json"}
)
print(response.content)
```

```python Cloud Deployment
import os
import requests

URL = "https://api.celesto.ai/v1/deploy/apps/APP-ID/chat"
CELESTO_API_KEY = os.environ.get("CELESTO_API_KEY")

headers = {
    "Authorization": f"Bearer {CELESTO_API_KEY}",
    "Content-Type": "application/json",
}

response = requests.post(
    URL,
    json={"input": "how are you?"},
    headers=headers,
)
print(response.content)
```

```bash cURL
curl -X 'POST' \
  'http://localhost:8000/chat' \
  -H 'accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
  "input": "What is the weather in London?"
}'
```
