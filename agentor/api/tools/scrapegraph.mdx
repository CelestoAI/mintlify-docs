The `ScrapeGraphAI` tool provides AI-powered web scraping capabilities, including smart scraping with natural language prompts, search scraping, and website crawling.

## Installation

```bash  theme={null}
pip install agentor[scrapegraph]
```

## Class signature

```python  theme={null}
class ScrapeGraphAI(BaseTool):
    name = "scrapegraph"
    description = "AI-powered web scraping tool"

    def __init__(self, api_key: Optional[str] = None)
```

<ParamField path="api_key" type="str" default="None">
  ScrapeGraphAI API key. Falls back to the `SCRAPEGRAPH_API_KEY` environment variable if not provided.
</ParamField>

## Methods

### smartscraper

Scrape a website using a natural language prompt to extract specific data.

```python  theme={null}
@capability
def smartscraper(self, website_url: str, user_prompt: str) -> str
```

<ParamField path="website_url" type="str" required>
  The URL to scrape.
</ParamField>

<ParamField path="user_prompt" type="str" required>
  Natural language description of what data to extract.
</ParamField>

### searchscraper

```python  theme={null}
@capability
```

<ParamField path="user_prompt" type="str" required>

</ParamField>

<ParamField path="num_results" type="int" default="3">
  Number of search results to process.
</ParamField>

<ParamField path="extraction_mode" type="bool" default="True">

## Usage

```python  theme={null}
from agentor import Agentor
from agentor.tools import ScrapeGraphAI

agent = Agentor(
    name="Web Researcher",
    model="gpt-5-mini",
    tools=[ScrapeGraphAI()],
    instructions="Scrape websites to answer user questions."
)

result = agent.run("Extract the pricing information from https://example.com/pricing")
print(result)
```
