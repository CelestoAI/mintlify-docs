title: "Celesto Gatekeeper"
description: "Connect your end users to third-party tools like Google Drive using CelestoSDK."
---

Delegated Access lets you connect your end users (subjects) to third-party providers such as Google Drive while keeping access scoped to your project.

## Prerequisites

- A Celesto API key in `CELESTO_API_KEY`
- Your project name in `CELESTO_PROJECT_NAME`

## Quickstart script

Use this complete script to start a connection, list active connections, and list Drive files once OAuth completes.

```python gatekeeper.py
import os
from celesto_sdk.sdk import CelestoSDK

api_key = os.environ["CELESTO_API_KEY"]
project_name = os.environ["CELESTO_PROJECT_NAME"]
client = CelestoSDK(api_key)

# ====================================================================

# Initiate connection (returns oauth_url if authorization is required)
response = client.gatekeeper.connect(
    subject="user:adam@acme.com",  # Unique identifier for the user 
    provider="google_drive",
    project_name=project_name,
)
print("connect:", response)

oauth_url = response.get("oauth_url")
if oauth_url:
    print("OAuth URL:", oauth_url)
    print("Complete OAuth flow before continuing...")
    raise SystemExit

connection_id = response.get("connection_id")
if not connection_id:
    raise SystemExit("No connection_id returned - check OAuth flow")

# ====================================================================

# List current connections
connections = client.gatekeeper.list_connections(project_name=project_name)
print("connections:", connections)

# ====================================================================

# List Drive files for the subject
files = client.gatekeeper.list_drive_files(
    project_name=project_name,
    subject="user:adam@acme.com",
    page_size=10,
    include_folders=True,
)
print("drive_files:", files)
```

## How the flow works

<Steps>
  <Step title="Create a connection">
    You call `connect` with a subject and project name. If the subject has not authorized yet, you receive an OAuth URL.

    <Check>
      You get `status: redirect` and an `oauth_url`.
    </Check>
  </Step>

  <Step title="Complete OAuth">
    You send your user to the OAuth URL and complete consent. The provider calls Celesto back to finalize the connection.

    <Check>
      The connection becomes `ACTIVE` for that subject.
    </Check>
  </Step>

  <Step title="Use delegated access">
    You list connections, fetch file metadata, and optionally revoke access when you are done.
  </Step>
</Steps>

## SDK methods

### `connect`

Signature: `connect(subject: str, project_name: str, provider: str = "google_drive", redirect_uri: str | None = None) -> dict`

**Parameters**

- `subject`: Stable identifier for your end user (for example, `user:acme:alice`)
- `project_name`: Your Celesto project name
- `provider`: Provider key. Use `google_drive` for Google Drive
- `redirect_uri`: Optional custom redirect URI after OAuth completion

### `list_connections`

Signature: `list_connections(project_name: str, status_filter: str | None = None) -> dict`

**Parameters**

- `project_name`: Your Celesto project name
- `status_filter`: `ACTIVE`, `PENDING`, or `REVOKED`

### `get_connection`

Signature: `get_connection(connection_id: str) -> dict`

**Parameters**

- `connection_id`: Delegated connection ID

### `list_drive_files`

Signature: `list_drive_files(project_name: str, subject: str, page_size: int = 20, page_token: str | None = None, folder_id: str | None = None, query: str | None = None, include_folders: bool = True, order_by: str | None = None) -> dict`

**Parameters**

- `project_name`: Your Celesto project name
- `subject`: Subject identifier tied to the delegated connection
- `page_size`: Number of files to return (1-1000)
- `page_token`: Token from a previous response for pagination
- `folder_id`: Google Drive folder ID. Defaults to root unless `query` is provided
- `query`: Google Drive search query (`q` parameter)
- `include_folders`: Include folders in the results
- `order_by`: Google Drive `orderBy` parameter

Notes:
- If access rules are active, a page may contain fewer than `page_size` results after filtering. Use `next_page_token` to continue.

### `update_access_rules`

Signature: `update_access_rules(connection_id: str, allowed_folders: list[str] | None = None, allowed_files: list[str] | None = None) -> dict`

**Parameters**

- `connection_id`: Delegated connection ID
- `allowed_folders`: List of Google Drive folder IDs with recursive access
- `allowed_files`: List of individual Google Drive file IDs

Notes:
- Setting both lists to empty blocks all access. Use `clear_access_rules` to remove restrictions.

### `clear_access_rules`

Signature: `clear_access_rules(connection_id: str) -> dict`

**Parameters**

- `connection_id`: Delegated connection ID

### `revoke_connection`

Signature: `revoke_connection(connection_id: str) -> dict`

**Parameters**

- `connection_id`: Delegated connection ID to revoke

## Troubleshooting

<AccordionGroup>
  <Accordion title="OAuth is not configured for the provider">
    - Ensure Google OAuth is configured for delegated access in your Celesto settings.
    - Verify you are using `provider="google_drive"` and the correct project name.
  </Accordion>
  <Accordion title="Connection stays in PENDING">
    - Make sure the user completed the OAuth flow in the browser.
    - Check that the callback URL is reachable from the OAuth provider.
  </Accordion>
</AccordionGroup>
