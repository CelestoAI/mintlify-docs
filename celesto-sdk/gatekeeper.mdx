Delegated Access lets you connect your end users (subjects) to third-party providers such as Google Drive while keeping access scoped to your project.

## Prerequisites

<Info>
  You can find your API key and project name in the [Celesto Dashboard](https://celesto.ai/dashboard).
</Info>

Set the following environment variables:

- `CELESTO_API_KEY`: Your Celesto API key
- `CELESTO_PROJECT_NAME`: Your project name

Install the SDK:

<CodeGroup>

```bash Python
pip install celesto
```

```bash JavaScript
npm install @celestoai/sdk
```

</CodeGroup>

## Quickstart script

Use this complete script to start a connection, list active connections, and list Drive files once OAuth completes.

<CodeGroup>

```python gatekeeper.py
import os
from celesto import Celesto


project_name = "Default"
subject = "user:acme:alice"  # Unique identifier for your end user

client = Celesto()

# ====================================================================

# Initiate connection (returns oauth_url if authorization is required)
response = client.gatekeeper.connect(
    subject=subject,
    provider="google_drive",
    project_name=project_name,
)
print("connect:", response)

if response.get("oauth_url"):
    print("OAuth URL:", response["oauth_url"])
    print("Complete OAuth flow before continuing...")
    raise SystemExit

print("Connected! Status:", response.get("status"))

# ====================================================================

# List current connections
connections = client.gatekeeper.list_connections(project_name=project_name)
print("connections:", connections)

# ====================================================================

# List Drive files for the subject
files = client.gatekeeper.list_drive_files(
    project_name=project_name,
    subject=subject,
    page_size=10,
    include_folders=True,
)
print("drive_files:", files)

# ====================================================================

# Update access rules (restrict to specific folders)
# rules = client.gatekeeper.update_access_rules(
#     subject=subject,
#     project_name=project_name,
#     allowed_folders=["folder_id_1", "folder_id_2"],
# )
# print("access_rules:", rules)

# ====================================================================

# Revoke connection when done
# client.gatekeeper.revoke_connection(
#     subject=subject,
#     project_name=project_name,
# )
```

```ts gatekeeper.ts
import { Celesto } from "@celestoai/sdk";

const projectName = "Default";
const subject = "user:acme:alice"; // Unique identifier for your end user

const client = new Celesto({
  token: process.env.CELESTO_API_KEY,
  // baseUrl: "https://api.celesto.ai",
});

const run = async () => {
  // `provider` defaults to "google_drive" — pass it explicitly to override.
  const connect = await client.gatekeeper.connect({
    subject,
    projectName,
  });
  console.log("connect:", connect);

  if (connect.status === "redirect" && connect.oauthUrl) {
    console.log("OAuth URL:", connect.oauthUrl);
    console.log("Complete OAuth flow before continuing...");
    return;
  }

  const connections = await client.gatekeeper.listConnections({ projectName });
  console.log("connections:", connections);

  const files = await client.gatekeeper.listDriveFiles({
    projectName,
    subject,
    pageSize: 10,
    includeFolders: true,
  });
  console.log("drive_files:", files);

  // Update access rules (restrict to specific folders)
  // const rules = await client.gatekeeper.updateAccessRules({
  //   subject,
  //   projectName,
  //   accessRules: { allowedFolders: ["folder_id_1", "folder_id_2"] },
  // });
  // console.log("access_rules:", rules);

  // Revoke connection when done
  // await client.gatekeeper.revokeConnection({ subject, projectName });
};

run().catch(console.error);
```

## How the flow works

<Steps>
  <Step title="Create a connection">
    You call `connect` with a subject and project name. If the subject has not authorized yet, you receive an OAuth URL.

    <Check>
      You get `status: redirect` and an `oauth_url`.
    </Check>
  </Step>

  <Step title="Complete OAuth">
    You send your user to the OAuth URL and complete consent. The provider calls Celesto back to finalize the connection.

    <Check>
      The connection becomes `ACTIVE` for that subject.
    </Check>
  </Step>

  <Step title="Use delegated access">
    You list connections, fetch file metadata, and optionally revoke access when you are done.
  </Step>
</Steps>

## SDK methods

<Note>
  Python uses snake_case parameters (e.g., `project_name`, `page_size`). JavaScript uses camelCase (e.g., `projectName`, `pageSize`).
</Note>

### `connect`

Signature:

<CodeGroup>

```python Python
connect(
    subject: str, 
    project_name: str, 
    provider: str = "google_drive", 
    redirect_uri: str | None = None
) -> dict
```

```ts JavaScript
connect(payload: {
  subject: string;
  projectName: string;
  provider?: string;
  redirectUri?: string;
}): Promise<GatekeeperConnectResponse>
```

</CodeGroup>

**Parameters**

<ParamField body="subject" type="string" required>
  Stable identifier for your end user (for example, `user:acme:alice`)
</ParamField>

<ParamField body="project_name" type="string" required>
  Your Celesto project name
</ParamField>

<ParamField body="provider" type="string" default="google_drive">
  Provider key. Use `google_drive` for Google Drive
</ParamField>

<ParamField body="redirect_uri" type="string">
  Optional custom redirect URI after OAuth completion
</ParamField>

**Parameters**

<ParamField body="project_name" type="string" required>

<ParamField body="subject" type="string" required>

</ParamField>

<ParamField body="page_size" type="integer" default="20">

</ParamField>

<ParamField body="page_token" type="string">
  Token from a previous response for pagination
</ParamField>

<ParamField body="folder_id" type="string">

</ParamField>

<ParamField body="query" type="string">
  Google Drive search query (`q` parameter)
</ParamField>

<ParamField body="include_folders" type="boolean" default="true">

</ParamField>

<ParamField body="order_by" type="string">
  Google Drive `orderBy` parameter
</ParamField>

<Note>
  If access rules are active, a page may contain fewer than `page_size` results after filtering. Use `next_page_token` to continue.
</Note>

## Troubleshooting

<AccordionGroup>
  <Accordion title="OAuth is not configured for the provider">
    - Ensure Google OAuth is configured for delegated access in your Celesto settings.
    - Verify you are using `provider="google_drive"` and the correct project name.
  </Accordion>
  <Accordion title="Connection stays in PENDING">
    - Make sure the user completed the OAuth flow in the browser.
    - Check that the callback URL is reachable from the OAuth provider.
  </Accordion>
</AccordionGroup>
