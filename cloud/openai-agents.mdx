Give your agent a tool that runs work on a separate Linux computer instead of your machine. The tool below opens a Celesto computer, checks its operating system, and removes the computer when it finishes.

## Install the SDKs

```bash
pip install 'celesto>=0.1.15' openai-agents
```

Set `OPENAI_API_KEY` for the agent and `CELESTO_API_KEY` for the cloud computer. Keep the keys in your application's environment, not in commands sent to the computer.

## Give the agent a tool

```python inspect_computer.py
from agents import Agent, Runner, function_tool
from celesto import CloudComputer


@function_tool
def inspect_computer() -> str:
    """Report the operating system of a fresh Celesto computer."""
    with CloudComputer(size_id="micro") as computer:
        result = computer.run("uname -a")
        if result.exit_code != 0:
            raise RuntimeError(f"uname exited with code {result.exit_code}")
        return result.stdout.strip()


agent = Agent(
    name="Computer inspector",
    instructions="Use inspect_computer to report the computer's operating system.",
    tools=[inspect_computer],
)

if __name__ == "__main__":
    result = Runner.run_sync(agent, "What operating system is the computer running?")
    print(result.final_output)
```

The `with` block starts the computer and deletes it when the tool returns. Use [a named size](/cloud/features/resources) to give a workload more CPU, memory, or disk.

The current Celesto package exposes `CloudComputer`, not the older `celesto.integrations.openai_agents` session adapter. The tool approach does not give the agent a persistent workspace automatically.

## Resume a session later

To reuse files across tool calls or agent runs, [keep the computer](/cloud/features/persistence) instead of creating it inside the tool every time. Save the computer ID in your application and reconnect with `CloudComputer.get(computer_id)`. Manage the computer's lifetime separately from the agent's.
