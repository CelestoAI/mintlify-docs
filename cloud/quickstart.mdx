This quickstart creates one sandboxed computer, runs `uname -a`, prints the output, and deletes the computer. You can use the language selector to switch the whole example between Python and TypeScript.

## Before you start

Open [API key](https://celesto.ai/api-key) in the Celesto console. Sign in or create an account when prompted, then set the default key shown there as `CELESTO_API_KEY` before running either example. It already has full access to its organization.

If you choose a named key for an SDK or REST integration, this example needs all three permissions:

| Permission | Why this example needs it |
|---|---|
| **See your computers** (`computers:read`) | Check the computer's startup and state. |
| **Create, start, stop computers and run commands** (`computers:exec`) | Create the computer and run the command. |
| **Delete computers** (`computers:admin`) | Clean up the computer when the example finishes. |

The named-key form starts with read access only.

<Note>
  The free trial covers Micro and allows two retained sandboxes per organization.
  Stopped and failed sandboxes still count. Reuse a computer, delete one when
  you are finished, or add prepaid credit before creating more. A
  `trial_retained_sandbox_limit_reached` error includes the allowed `limit`;
  waiting alone does not free a retained slot. Other HTTP 429 errors can have
  different recovery steps.
</Note>

<View title="Python" icon="python">
  ## Install the Python SDK

  Use Python 3.11 or newer.

  ```bash
  python -m pip install --upgrade celesto
  ```

  ## Run your first computer

  Create `quickstart.py`:

  ```python quickstart.py
  from celesto import CloudComputer

  with CloudComputer() as computer:
      print(computer.run("uname -a").stdout)
  ```

  Run it:

  ```bash
  export CELESTO_API_KEY="your-api-key"
  python quickstart.py
  ```

  <Check>
    The script prints Linux system information. Exiting the `with` block deletes
    the computer.
  </Check>

</View>

<View title="TypeScript" icon="js">
  ## Install the TypeScript SDK

  ```bash
  npm install @celestoai/sdk
  npm install --save-dev tsx typescript
  ```

  ## Run your first computer

  Create `quickstart.ts`:

  ```ts quickstart.ts
  import { Computer } from "@celestoai/sdk";

  const computer = await Computer.create();
  while (computer.status !== "running") {
    await new Promise(resolve => setTimeout(resolve, 1000));
    await computer.refresh();
  }
  console.log((await computer.run("uname -a")).stdout);
  await computer.delete();
  ```

  Run it:

  ```bash
  export CELESTO_API_KEY="your-api-key"
  npx tsx quickstart.ts
  ```

  <Check>
    The script prints Linux system information and deletes the computer.
  </Check>

  The SDK reads `CELESTO_API_KEY` from your environment. The loop waits for
  startup before running the command.
