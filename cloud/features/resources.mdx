A Celesto cloud computer size sets how much processing power, memory, and disk space your computer gets, and what it costs per hour. Choose a size before the computer starts. Start with Micro for small jobs, then move to a bigger size when your agent builds code, installs packages, opens large files, or runs a web app.

A computer's root disk and its workspace storage both keep your data, but they serve different jobs. The root disk holds the operating system and tools, and its size comes with the computer size you choose. Use CelestoFS workspace storage for large project files, repositories, datasets, and artifacts. See [Petabyte-scale storage for AI agent sandboxes](/cloud/features/petabyte-storage).

## Start with a template

A template is a ready-made starting setup for a computer. It determines which tools are installed. A named size determines how much CPU, memory, and disk space the computer gets.

Use `coding-agent` when your workflow needs common coding tools preinstalled. To start every computer with your own packages, [build a custom template](/cloud/features/custom-templates).

List the available templates:

<CodeGroup>

```ts TypeScript
import { Computer } from "@celestoai/sdk";

const templates = await Computer.listTemplates();

for (const template of templates) {
  console.log(`${template.id}: ${template.displayName}`);
}
```

```bash CLI
celesto computer templates --cloud
```

</CodeGroup>

## Choose a named size

Choose a size by ID, such as `micro` or `large`. Each size includes a fixed root disk for the operating system and tools. A vCPU is a virtual CPU core.

| Size | CPU | Memory | Root disk | Price |
| --- | ---: | ---: | ---: | ---: |
| Micro | 1 vCPU | 2 GB | 20 GB | $0.015/hour |
| Small | 1 vCPU | 4 GB | 25 GB | $0.020/hour |
| Standard | 2 vCPU | 4 GB | 30 GB | $0.030/hour |
| Memory | 2 vCPU | 8 GB | 40 GB | $0.040/hour |
| Large | 4 vCPU | 16 GB | 60 GB | $0.080/hour |
| XL | 8 vCPU | 32 GB | 100 GB | $0.160/hour |

The free trial covers machines up to Standard (2 vCPUs, 4 GB RAM). Larger sizes require eligible workspace credit. Some promotions cover specific sizes. See [Celesto pricing](https://celesto.ai/pricing) for trial details or request `GET /v1/billing/sizes` for the current catalog.

For built-in templates, the default is Micro on the trial and Standard outside it. Choose an explicit size to get the same resources across accounts. Cloud computers reject custom CPU, memory, and disk values.

<ParamField body="size_id" type="string">
  Named size ID. Use `size_id` in Python and the API, `sizeId` in TypeScript, or `--size` in the CLI.
</ParamField>

<ParamField body="template_id" type="string" default="scratch">
  Ready-made starting setup for the computer. Use `coding-agent` when your agent needs coding tools already installed.
</ParamField>

## Create a larger Celesto cloud computer

Create a larger computer when your current size does not have enough room for the job. This example requires an account that can create Standard computers. It gives the `coding-agent` template 2 vCPUs, 4 GB of memory, and a 30 GB root disk.

<CodeGroup>

```python Python
from celesto import CloudComputer

with CloudComputer(template_id="coding-agent", size_id="standard") as computer:
    print(computer.id)
```

```ts TypeScript
import { Computer } from "@celestoai/sdk";

const computer = await Computer.create({
  templateId: "coding-agent",
  sizeId: "standard",
});

console.log(computer.name);
console.log(`${computer.vcpus} CPU`);
console.log(`${computer.ramMb} MB memory`);
console.log(`${computer.diskSizeMb} MB disk`);
```

```bash CLI
celesto computer create --cloud --template coding-agent --size standard
```

</CodeGroup>

<Check>
  The computer uses the Standard resources listed above. If you created it with TypeScript or the CLI, [delete the computer](/cloud/computers) when you no longer need it.
</Check>

## Pick a computer size for your workload

Use the smallest computer that can finish the job. Increase the setting that matches the problem you see.

| Workload | Start with |
|---|---|
| Quick shell commands | Micro |
| Coding agent with package installs | Standard `coding-agent` |
| Large repository builds | Large, plus CelestoFS workspace storage |
| Data processing or notebooks | Memory or Large, plus CelestoFS workspace storage |
| Hosted preview app | Standard, plus [port publishing](/cloud/features/publish-ports) |

<Tip>
  Move to the next named size when builds are slow, programs run out of memory, or system tools run out of disk space. Each larger size also includes a larger root disk. Use CelestoFS for large workspace files.
</Tip>
