You can choose a named computer size before a Celesto computer starts. Start with Micro for small jobs, then move to a bigger size when your agent builds code, installs packages, opens large files, or runs a web app.

Root disk and workspace storage are both durable, but they serve different jobs. The root disk holds the operating system and tools, and its size comes with the computer size you choose. Use CelestoFS workspace storage for large project files, repositories, datasets, and artifacts. See [Petabyte-scale storage for AI agent sandboxes](/cloud/features/petabyte-storage).

## Start with a template

A template is a ready-made starting setup for a computer. It includes an operating system, useful tools, and default resource sizes.

Use `coding-agent` when your workflow needs common coding tools. Use the template defaults when you are running quick scripts or trying Celesto for the first time.

<CodeGroup>

```python Python
from celesto import Computer


templates = Computer.list_templates()

for template in templates:
    print(
        f"{template['id']}: "
        f"{template['default_vcpus']} CPU, "
        f"{template['default_ram_mb']} MB memory"
    )
```

```ts TypeScript
import { Computer } from "@celestoai/sdk";

const templates = await Computer.listTemplates();

for (const template of templates) {
  console.log(
    `${template.id}: ${template.defaultVcpus} CPU, ${template.defaultRamMb} MB memory`,
  );
}
```

```bash CLI
celesto computer templates
```

</CodeGroup>

## Choose a named size

CPU and memory must match one of these named sizes. Each size includes a fixed root disk for the operating system and tools. A vCPU is a virtual CPU core.

| Size | CPU | Memory | Root disk | Price |
| --- | ---: | ---: | ---: | ---: |
| Micro (default) | 1 vCPU | 2 GB | 20 GB | $0.015/hour |
| Small | 1 vCPU | 4 GB | 25 GB | $0.020/hour |
| Standard | 2 vCPU | 4 GB | 30 GB | $0.030/hour |
| Memory | 2 vCPU | 8 GB | 40 GB | $0.040/hour |
| Large | 4 vCPU | 16 GB | 60 GB | $0.080/hour |
| XL | 8 vCPU | 32 GB | 100 GB | $0.160/hour |

The free trial includes Micro only. Add credit to your account to unlock the other sizes. See [Celesto pricing](https://celesto.ai/pricing) for current rates and trial details.

Omit both CPU and memory to use the template default. When you set them explicitly, choose both values from the same row. Mixed combinations such as 2 vCPU with 2 GB memory are rejected.

<ParamField body="cpus" type="integer">
  CPU value from a named size. Use together with the matching `memory` value.
</ParamField>

<ParamField body="memory" type="integer">
  Memory in MB from a named size. Use together with the matching `cpus` value.
</ParamField>

<ParamField body="disk_size_mb" type="integer">
  Root disk storage inside the computer in MB. Each named size includes a fixed root disk, such as `30720` (30 GB) for Standard, so you can leave this out. If you set it, use the value from the same row as `cpus` and `memory`. For large workspace files, use CelestoFS.
</ParamField>

<ParamField body="template_id" type="string" default="scratch">
  Ready-made starting setup for the computer. Use `coding-agent` when your agent needs coding tools already installed.
</ParamField>

## Create a larger computer

Create a larger computer when the default template does not have enough room for the job. This example creates a Standard `coding-agent` computer with 2 CPUs and 4096 MB of memory. Standard includes a 30 GB root disk.

<CodeGroup>

```python Python
from celesto import Computer


computer = Computer(
    template_id="coding-agent",
    cpus=2,
    memory=4096,
)

print(computer.name)
print(f"{computer.vcpus} CPU")
print(f"{computer.ram_mb} MB memory")
print(f"{computer.disk_size_mb} MB disk")

computer.delete()
```

```ts TypeScript
import { Computer } from "@celestoai/sdk";

const computer = await Computer.create({
  templateId: "coding-agent",
  cpus: 2,
  memory: 4096,
});

console.log(computer.name);
console.log(`${computer.vcpus} CPU`);
console.log(`${computer.ramMb} MB memory`);
console.log(`${computer.diskSizeMb} MB disk`);

await computer.delete();
```

```bash CLI
celesto computer create --template coding-agent --cpus 2 --memory 4096
```

</CodeGroup>

<Check>
  The response shows the CPU, memory, and disk size assigned to the new computer.
</Check>

## Pick a starting size

Use the smallest computer that can finish the job. Increase the setting that matches the problem you see.

| Workload | Start with |
|---|---|
| Quick shell commands | Micro or template defaults |
| Coding agent with package installs | Standard `coding-agent` |
| Large repository builds | Large, plus CelestoFS workspace storage |
| Data processing or notebooks | Memory or Large, plus CelestoFS workspace storage |
| Hosted preview app | Standard, plus port publishing |

<Tip>
  Move to the next named size when builds are slow, programs run out of memory, or system tools run out of disk space. Each larger size also includes a larger root disk. Use CelestoFS for large workspace files.
</Tip>
