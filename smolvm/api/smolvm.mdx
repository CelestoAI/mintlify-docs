---
title: "SmolVM"
description: "Create, launch, reconnect to, and snapshot a single SmolVM sandbox"
---

`SmolVM` is the main Python interface for one sandbox. Use it for the default zero-config sandbox, or use `SmolVM.from_image()` when you want to launch a custom `BootImage`.

## Constructor

```python  theme={null}
SmolVM(
    config: VMConfig | None = None,
    *,
    vm_id: str | None = None,
    image: str | None = None,
    data_dir: Path | None = None,
    socket_dir: Path | None = None,
    backend: str | None = None,
    os: GuestOS | str | None = None,
    memory: int | None = None,
    disk_size: int | None = None,
    ssh_user: str = "root",
    ssh_key_path: str | None = None,
    ssh_password: str | None = None,
    comm_channel: Literal["ssh", "vsock"] | None = None,
    internet_settings: InternetSettings | dict[str, Any] | None = None,
    mounts: list[str] | None = None,
    writable_mounts: bool = False,
    callbacks: list[Callback] | None = None,
)
```

<ParamField path="config" type="VMConfig | None" default="None">
  Explicit VM configuration. Mutually exclusive with `vm_id`, `image`, `memory`, `disk_size`, and `os`.
</ParamField>

<ParamField path="vm_id" type="str | None" default="None">
  Existing VM ID to reconnect to. Mutually exclusive with `config` and `image`.
</ParamField>

<ParamField path="image" type="str | None" default="None">
  Local image path, `file://` URI, or S3 image reference for image-based auto configuration.
</ParamField>

<ParamField path="backend" type="str | None" default="None">
  Runtime backend override. Options are `"firecracker"`, `"qemu"`, `"libkrun"`, or `"auto"`.
</ParamField>

<ParamField path="os" type="GuestOS | str | None" default="None">
  Guest operating system for auto-config mode. Local image paths need this when the image does not self-identify.
</ParamField>

<ParamField path="memory" type="int | None" default="None">
  Guest memory in MiB for auto-config mode.
</ParamField>

<ParamField path="disk_size" type="int | None" default="None">
  Root disk size in MiB for auto-config mode.
</ParamField>

<ParamField path="ssh_user" type="str" default='"root"'>
  SSH user for command execution.
</ParamField>

<ParamField path="ssh_key_path" type="str | None" default="None">
  SSH private key path. If omitted, SmolVM tries default SSH auth and then `~/.smolvm/keys/id_ed25519`.
</ParamField>

<ParamField path="ssh_password" type="str | None" default="None">
  SSH password for images that use password authentication.
</ParamField>

<ParamField path="comm_channel" type='"ssh" | "vsock" | None' default="None">
  Host-to-guest control channel. `None` lets SmolVM choose.
</ParamField>

<ParamField path="internet_settings" type="InternetSettings | dict[str, Any] | None" default="None">
  Internet access settings for the sandbox.
</ParamField>

<ParamField path="mounts" type="list[str] | None" default="None">
  Host workspace mounts to expose in the guest.
</ParamField>

<ParamField path="writable_mounts" type="bool" default="False">
  Whether workspace mounts are writable inside the guest.
</ParamField>

### Basic usage

```python  theme={null}
from smolvm import SmolVM

with SmolVM(memory=1024, disk_size=2048) as vm:
    result = vm.run("python3 --version")
    print(result.output)
```

## from_image

```python  theme={null}
@classmethod
SmolVM.from_image(
    image: BootImage,
    *,
    vm_id: str | None = None,
    name_prefix: str = "sbx",
    data_dir: Path | None = None,
    socket_dir: Path | None = None,
    backend: str | None = None,
    arch: str | None = None,
    vcpus: int = 1,
    memory_mb: int = 512,
    guest_os: GuestOS | str = GuestOS.ALPINE,
    network: Literal["tap", "slirp"] | None = None,
    port_forwards: list[PortForwardConfig | dict[str, Any]] | None = None,
    vsock: VsockConfig | dict[str, Any] | None = None,
    comm_channel: Literal["ssh", "vsock"] | None = None,
    disk_mode: Literal["isolated", "shared"] = "isolated",
    disk_size_mb: int | None = None,
    grow_filesystem: bool = False,
    ssh_user: str = "root",
    ssh_key_path: str | None = None,
    ssh_password: str | None = None,
    internet_settings: InternetSettings | dict[str, Any] | None = None,
    mounts: list[str] | None = None,
    writable_mounts: bool = False,
    callbacks: list[Callback] | None = None,
) -> SmolVM
```

Create a VM from a custom `BootImage`. The image supplies root filesystem and boot metadata; `from_image()` adds runtime settings and delegates disk isolation, resize, network setup, and lifecycle management to SmolVM.

<ParamField path="image" type="BootImage" required>
  Custom image descriptor.
</ParamField>

<ParamField path="vcpus" type="int" default="1">
  Virtual CPU count for the sandbox.
</ParamField>

<ParamField path="memory_mb" type="int" default="512">
  Guest memory in MiB.
</ParamField>

<ParamField path="disk_mode" type='"isolated" | "shared"' default='"isolated"'>
  Disk lifecycle mode. Isolated mode creates a per-VM disk; shared mode boots directly from the image artifact.
</ParamField>

<ParamField path="disk_size_mb" type="int | None" default="None">
  Requested isolated disk size in MiB. SmolVM refuses to resize shared base images.
</ParamField>

<ParamField path="grow_filesystem" type="bool" default="False">
  Grow the guest filesystem after resizing when SmolVM can do so safely. This currently supports raw ext4 images.
</ParamField>

<ParamField path="network" type='"tap" | "slirp" | None' default="None">
  QEMU network mode. `port_forwards` require `backend="qemu"` and `network="slirp"`.
</ParamField>

### Example

```python  theme={null}
from smolvm import DockerRootfsBuilder, DirectKernelBoot, SmolVM

image = DockerRootfsBuilder(
    name="worker",
    dockerfile="FROM alpine:3.20\nRUN apk add --no-cache python3\n",
    rootfs_size_mb=1024,
).ensure(
    backend="qemu",
    boot=DirectKernelBoot(init=None),
)

with SmolVM.from_image(
    image,
    backend="qemu",
    memory_mb=1024,
    disk_size_mb=2048,
) as vm:
    print(vm.status)
```

## snapshot

```python  theme={null}
vm.snapshot(
    snapshot_id: str | None = None,
    *,
    snapshot_type: SnapshotType | str = SnapshotType.FULL,
    resume_source: bool = False,
) -> SnapshotInfo
```

Create a snapshot of the VM.

<ParamField path="snapshot_type" type='SnapshotType | "full" | "diff" | "disk"' default="SnapshotType.FULL">
  How much state to store. Use `"full"` for a self-contained disk and memory snapshot, `"diff"` for a smaller snapshot that depends on the base image, or `"disk"` for a self-contained disk-only snapshot that cold-boots on restore.
</ParamField>

```python  theme={null}
snapshot = vm.snapshot(
    snapshot_id="before-upgrade",
    snapshot_type="disk",
    resume_source=True,
)
```

## Environment methods

```python  theme={null}
vm.set_env_vars({"API_URL": "https://api.example.com"})
vm.list_env_vars()
vm.unset_env_vars(["API_URL"])
```

Environment variable methods require an SSH-capable guest.

## Port forwarding methods

```python  theme={null}
host_port = vm.expose_local(guest_port=8000, host_port=None)
vm.unexpose_local(host_port=host_port, guest_port=8000)
```

Expose or remove localhost-only TCP forwards.
