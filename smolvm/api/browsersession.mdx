## Overview

`BrowserSession` gives you a real Chromium browser running inside a SmolVM sandbox. You can automate it with Playwright, take screenshots, transfer files, or watch the session live through noVNC — all without installing a browser on your host.

Use browser sessions when your agent or script needs to interact with websites, fill out forms, capture screenshots, or perform computer-use tasks.

## Import

```python

```

## Browser automation

### connect\_playwright

Connect a Playwright `Browser` instance to the running browser session over CDP.

```python  theme={null}
def connect_playwright(self) -> Browser
```

<ResponseField name="return" type="Browser">
  A Playwright `Browser` object you can use to create pages, navigate, click, and extract content.
</ResponseField>

<Note>
  You need `playwright` installed locally. Install it with `pip install playwright`.
</Note>

**Example:**

```python
from smolvm import BrowserSession

with BrowserSession() as session:
    browser = session.connect_playwright()
    page = browser.new_page()
    page.goto("https://example.com")
    print(page.title())
    browser.close()
```

## Context manager

BrowserSession supports the `with` statement for automatic lifecycle management:

```python  theme={null}
with BrowserSession() as session:
    browser = session.connect_playwright()
    page = browser.new_page()
    page.goto("https://example.com")
    # session automatically stops and deletes on exit
```

On entry (`__enter__`): starts the session if it was newly created.

On exit (`__exit__`): stops and deletes the session, releasing all resources.

## Usage examples

### Basic browser session

```python
from smolvm import BrowserSession

with BrowserSession() as session:
    browser = session.connect_playwright()
    page = browser.new_page()
    page.goto("https://news.ycombinator.com")
    titles = page.query_selector_all(".titleline > a")
    for t in titles[:5]:
        print(t.text_content())
    browser.close()
```

### Take a screenshot

```python
from smolvm import BrowserSession

with BrowserSession() as session:
    browser = session.connect_playwright()
    page = browser.new_page()
    page.goto("https://example.com")
    session.screenshot("example.png")
    browser.close()
```

### Custom browser configuration

```python
from smolvm import BrowserSession, BrowserSessionConfig, BrowserViewport

config = BrowserSessionConfig(
    viewport=BrowserViewport(width=1920, height=1080),
    mem_size_mib=2048,
    enable_video_recording=True,
)

with BrowserSession(config=config) as session:
    browser = session.connect_playwright()
    page = browser.new_page()
    page.goto("https://example.com")
    browser.close()
```

### Reconnect to an existing session

```python
from smolvm import BrowserSession

# First, create and keep a session running
session = BrowserSession()
session.start()
session_id = session.info.session_id

# Later, reconnect from another script
restored = BrowserSession.from_id(session_id)
browser = restored.connect_playwright()
# ...
restored.stop()
restored.delete()
```
