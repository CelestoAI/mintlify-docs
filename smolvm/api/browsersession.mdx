## Overview

The `BrowserSession` class manages disposable Chromium browser sessions that run inside SmolVM guest VMs. Each session provides a CDP endpoint for browser automation and an optional live-view URL for visual monitoring.

## Constructor

```python
BrowserSession(
    config: BrowserSessionConfig | None = None,
    *,
    session_id: str | None = None,
    data_dir: Path | None = None,
    socket_dir: Path | None = None,
    ssh_key_path: str | None = None,
)
```

<ParamField path="config" type="BrowserSessionConfig | None" default="None">
  Browser session configuration. Mutually exclusive with `session_id`. If both are omitted, a default headless session is created.
</ParamField>

<ParamField path="session_id" type="str | None" default="None">
  ID of an existing session to reconnect to. Mutually exclusive with `config`.
</ParamField>

<ParamField path="data_dir" type="Path | None" default="None">
  Override the default SmolVM data directory.
</ParamField>

<ParamField path="socket_dir" type="Path | None" default="None">
  Override the default socket directory.
</ParamField>

<ParamField path="ssh_key_path" type="str | None" default="None">
  SSH private key path for guest access.
</ParamField>

### Raises

* `ValueError`: If both `config` and `session_id` are provided.

## Context manager

BrowserSession implements the context manager protocol for automatic lifecycle management:

```python
with BrowserSession(BrowserSessionConfig(mode="live")) as session:
    # Session auto-starts on context entry
    print(session.cdp_url)
# Session auto-stops on context exit
```

On context entry (`__enter__`):
* Auto-starts the session if it was created (not reconnected) and is not yet ready

On context exit (`__exit__`):
* Auto-stops the session if it was created by this instance
* Releases all local resources via `close()`

## Usage examples

### Headless automation

```python
from smolvm import BrowserSession, BrowserSessionConfig

with BrowserSession(BrowserSessionConfig()) as session:
    browser = session.connect_playwright()
    page = browser.contexts[0].pages[0]
    page.goto("https://example.com")
    session.screenshot("output.png")
```

### Live mode with recording

```python
from smolvm import BrowserSession, BrowserSessionConfig

with BrowserSession(
    BrowserSessionConfig(
        mode="live",
        record_video=True,
        viewport={"width": 1440, "height": 900},
    )
) as session:
    print(f"Watch: {session.live_url}")
    print(f"Automate: {session.cdp_url}")
    # ... run automation ...
    session.collect_artifacts()
```

### Reconnecting to an existing session

```python
from smolvm import BrowserSession

session = BrowserSession.from_id("browser-abc12345")
print(f"Status: {session.status}")
print(f"CDP URL: {session.cdp_url}")
session.close()
```
