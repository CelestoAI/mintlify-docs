## Overview

The `BrowserSession` class manages a disposable Chromium browser running inside a SmolVM microVM. It handles the full lifecycle — provisioning the VM, starting the browser, exposing CDP and live-view endpoints, and tearing everything down when you are done.

## Constructor

```python
BrowserSession(
    config: BrowserSessionConfig | None = None,
    *,
    session_id: str | None = None,
    data_dir: Path | None = None,
    socket_dir: Path | None = None,
    ssh_key_path: str | None = None,
)
```

<ParamField path="config" type="BrowserSessionConfig | None" default="None">
  Session configuration. Mutually exclusive with `session_id`. If both are omitted, a default `BrowserSessionConfig()` is used (headless, ephemeral profile).
</ParamField>

<ParamField path="session_id" type="str | None" default="None">
  ID of an existing session to reconnect to. Mutually exclusive with `config`.
</ParamField>

<ParamField path="data_dir" type="Path | None" default="None">
  Override the default SmolVM data directory.
</ParamField>

<ParamField path="socket_dir" type="Path | None" default="None">
  Override the default socket directory.
</ParamField>

<ParamField path="ssh_key_path" type="str | None" default="None">
  SSH private key path. If omitted, SmolVM uses its default key.
</ParamField>

### Raises

* `ValueError`: If both `config` and `session_id` are provided.

## Lifecycle methods

### start

```python
def start(self, boot_timeout: float = 90.0) -> BrowserSession
```

Start the browser session. Boots the underlying VM, launches Chromium inside the guest, and exposes the CDP endpoint (and live-view endpoint if mode is `"live"`).

<ParamField path="boot_timeout" type="float" default="90.0">
  Maximum seconds to wait for the VM and browser to become ready.
</ParamField>

<ResponseField name="return" type="BrowserSession">
  Returns `self` for method chaining.
</ResponseField>

#### Raises

* `SmolVMError`: If the VM is unavailable, the CDP port is not exposed in time, or `network_policy_id` is set (not yet implemented).

### stop

```python
def stop(self) -> BrowserSession
```

Stop the browser session. Gracefully shuts down the guest browser, collects artifacts, deletes the VM, and removes persisted session state.

<ResponseField name="return" type="BrowserSession">
  Returns `self` for method chaining.
</ResponseField>

### delete

```python
def delete(self) -> None
```

Alias for `stop()`.

### close

```python
def close(self) -> None
```

Release local resources (Playwright runtime, SSH connections) without changing the remote session state. Use this when you want to disconnect from a session without stopping it.

## Context manager

`BrowserSession` implements the context manager protocol for automatic lifecycle management:

```python
from smolvm import BrowserSession, BrowserSessionConfig

with BrowserSession(BrowserSessionConfig(mode="live")) as session:
    # Session auto-starts on entry
    print(session.cdp_url)
# Session auto-stops on exit
```

**On entry (`__enter__`):** Calls `start()` if the session was created (not reconnected) and is not already ready.

**On exit (`__exit__`):** Calls `stop()` for sessions created by this instance, then `close()`.

## Usage examples

### Headless automation

```python
from smolvm import BrowserSession

with BrowserSession() as session:
    browser = session.connect_playwright()
    page = browser.new_context().new_page()
    page.goto("https://example.com")
    print(page.title())
```

### Live mode with video recording

```python
from smolvm import BrowserSession, BrowserSessionConfig

with BrowserSession(
    BrowserSessionConfig(
        mode="live",
        record_video=True,
        viewport={"width": 1440, "height": 900},
    )
) as session:
    session.open_live_view()
    browser = session.connect_playwright()
    page = browser.new_context().new_page()
    page.goto("https://example.com")

    session.screenshot("screenshot.png")
    session.collect_artifacts()
```
