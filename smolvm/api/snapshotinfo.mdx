---
title: "SnapshotInfo"
description: "Metadata for a saved SmolVM snapshot, including type, artifacts, and restore status"
---

`SnapshotInfo` tells you what SmolVM saved when it created a snapshot. It includes the snapshot type, backend, artifact paths, original VM config, and restore status.

## Fields

<ResponseField name="snapshot_id" type="string" required>
  Unique snapshot ID.
</ResponseField>

<ResponseField name="vm_id" type="string" required>
  Source VM ID.
</ResponseField>

<ResponseField name="backend" type='"firecracker" | "qemu" | "libkrun"' required>
  Backend used by the source VM.
</ResponseField>

<ResponseField name="snapshot_type" type='SnapshotType' default="SnapshotType.FULL">
  Snapshot type. Values are `"full"`, `"diff"`, and `"disk"`.
</ResponseField>

<ResponseField name="artifacts" type="SnapshotArtifacts" required>
  Files saved for this snapshot.

  <Expandable title="Snapshot artifact fields">
    <ResponseField name="state_path" type="Path | None">
      VM state file path when the snapshot type/backend writes one.
    </ResponseField>

    <ResponseField name="memory_path" type="Path | None">
      Guest memory file path when the snapshot type/backend writes one.
    </ResponseField>

    <ResponseField name="disk_path" type="Path">
      Saved disk artifact path.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vm_config" type="VMConfig" required>
  VM configuration captured at snapshot time.
</ResponseField>

<ResponseField name="network_config" type="NetworkConfig" required>
  Network configuration captured at snapshot time.
</ResponseField>

<ResponseField name="created_at" type="datetime" required>
  UTC timestamp when the snapshot was created.
</ResponseField>

<ResponseField name="restored" type="bool" default="false">
  Whether this snapshot has already been restored.
</ResponseField>

<ResponseField name="restored_vm_id" type="string | None" default="None">
  VM ID of the most recently restored instance, if any.
</ResponseField>

## Example

```python  theme={null}
from smolvm import SmolVM

with SmolVM(backend="qemu") as vm:
    snapshot = vm.snapshot(
        snapshot_id="filesystem-checkpoint",
        snapshot_type="disk",
        resume_source=True,
    )

    print(snapshot.snapshot_id)
    print(snapshot.snapshot_type)
    print(snapshot.artifacts.disk_path)
```
