# Celesto

[Celesto](https://github.com/CelestoAI/celesto) gives AI agents their own disposable computer. Each <Tooltip tip="A lightweight virtual machine that provides hardware-level isolation with near-instant startup, combining the speed of containers with the security of full VMs">microVM</Tooltip> boots in milliseconds, runs any code or software you throw at it, persists files and state across sessions, and disappears when you're done — built for scale in production.

## Quickstart

<Steps>
  <Step title="Install Celesto">
    ```bash
    curl -sSL https://celesto.ai/install.sh | bash
    ```

    This installs everything you need and configures your machine. See [Installation](/smolvm/installation) for manual install and requirements.
  </Step>
  <Step title="Run your first sandbox">
    <Tabs>
      <Tab title="Python">
        Create `quickstart.py`:

        ```python quickstart.py
        from celesto import Celesto
        
        vm = Celesto()
        result = vm.run("echo 'Hello from the sandbox!'")
        print(result.stdout.strip())
        vm.stop()
        ```

        Run it:

        ```bash
        python quickstart.py
        ```
      </Tab>
      <Tab title="CLI">
        ```bash
        celesto sandbox create --name my-sandbox
        celesto sandbox ssh my-sandbox
        echo 'Hello from the sandbox!'
        exit
        celesto sandbox stop my-sandbox
        ```
      </Tab>
    </Tabs>

    You should see:

    ```text
    Hello from the sandbox!
    ```
  </Step>
</Steps>

### CLI usage

Create and manage sandboxes from the terminal:

```bash
celesto sandbox create --name my-sandbox
celesto sandbox ssh my-sandbox
celesto sandbox list
celesto sandbox stop my-sandbox
```

Run coding agents in an isolated sandbox:

```bash
celesto claude start
celesto codex start
celesto opencode start
celesto pi start
```

Mount host directories for read-only access:

```bash
celesto sandbox create --mount ~/Projects/my-app
celesto sandbox create --mount ~/Projects/my-app:/code --mount ~/data:/mnt/data
```

Save and restore VM state with snapshots:

```bash
celesto sandbox snapshot create my-sandbox
celesto sandbox snapshot list
celesto sandbox snapshot restore snap_abc123 --resume
```

Start a visible browser sandbox:

```bash
celesto browser start --live
celesto browser list
celesto browser stop sess_a1b2c3
```

See the [CLI reference](/smolvm/cli/overview) for the full command list.

### Python SDK

Create and manage sandboxes from Python:

```python
from celesto import Celesto

with Celesto() as vm:
    result = vm.run("echo 'Hello from the sandbox!'")
    print(result.stdout.strip())
```

Customize memory and disk for heavier workloads:

```python
vm = Celesto(memory=2048, disk_size=4096)
```

Mount host directories:

```python
with Celesto(mounts=["~/Projects/my-app"]) as vm:
    result = vm.run("ls /workspace")
    print(result.stdout)
```

Expose a port from the sandbox to your host:

```python
with Celesto() as vm:
    vm.run("python3 -m http.server 8000 &")
    host_port = vm.expose_local(guest_port=8000)
    print(f"http://127.0.0.1:{host_port}/")
```

See the [API reference](/smolvm/api/smolvm) for the full SDK documentation.
