---
title: "celesto sandbox ssh"
description: "Use celesto sandbox ssh to open a real SSH session into a sandbox when you need SSH behavior instead of the faster Celesto shell."
---

`celesto sandbox ssh` opens an interactive SSH session to a sandbox. Use it when you need SSH-specific behavior, such as SSH agent forwarding, a custom key, or a user account other than `root`.

## Synopsis

```bash
celesto sandbox ssh <sandbox> [OPTIONS]
```

## Arguments

<ParamField path="sandbox" type="string" required>
  Name or ID of the sandbox to connect to.
</ParamField>

## Options

<ParamField path="--ssh-key" type="string">
  Path to the SSH private key.
</ParamField>

<ParamField path="--ssh-user" type="string" default="root">
  SSH user inside the sandbox.
</ParamField>

<ParamField path="--boot-timeout" type="number" default="30">
  Seconds to wait if Celesto needs to start the sandbox before connecting.
</ParamField>

## Examples

### Connect to a sandbox

```bash
celesto sandbox ssh my-sandbox
```

### Use a custom key

```bash
celesto sandbox ssh my-sandbox --ssh-key ~/.ssh/work_sandbox
```

### Connect as another user

```bash
celesto sandbox ssh ubuntu-box --ssh-user ubuntu
```

## Shell versus SSH

Use [`celesto sandbox shell`](/smolvm/cli/shell) for the fastest interactive shell on recent Linux images. It uses the Celesto guest agent when available. Use `celesto sandbox ssh` when you specifically need SSH.
