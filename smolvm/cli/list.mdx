---
title: "smolvm sandbox list"
description: "Use smolvm sandbox list to view sandboxes, filter by state or preset, and produce JSON for scripts."
---

`smolvm sandbox list` shows the sandboxes on your machine. Use it to find a sandbox name, check whether one is still running, or feed sandbox data into a script.

## Synopsis

```bash
smolvm sandbox list [OPTIONS]
```

## Examples

### List running sandboxes

```bash
smolvm sandbox list
```

### List every sandbox

```bash
smolvm sandbox list --all
```

### Filter by state

```bash
smolvm sandbox list --status stopped
```

### Filter by preset

A preset is a ready-made sandbox setup for an agent. Use `--preset` to show only sandboxes created by one preset. The table adds a Preset column so you can tell which agent produced each sandbox:

```bash
smolvm sandbox list --preset openclaw
# NAME              PRESET     STATUS   PID
# openclaw-work     openclaw   running  12345
```

Add `--all` to include that preset's sandboxes in every state:

```bash
smolvm sandbox list --preset openclaw --all
```

<Note>
  Preset filtering uses information saved when SmolVM creates a sandbox. Sandboxes created by older SmolVM releases and manually prepared sandboxes remain available through `smolvm sandbox list --all`, but do not appear in preset-filtered results. Their Preset column shows `-`.
</Note>

For OpenClaw specifically, the shortcut `smolvm openclaw list` shows only OpenClaw sandboxes and accepts the same `--all`, `--status`, and `--json` flags. See [Work with OpenClaw](/smolvm/features/coding-agents#work-with-openclaw) for the full workflow.

```bash
smolvm sandbox list --json
```

## Options

<ParamField path="--all" type="flag">
  Show every sandbox, including stopped, created, paused, and errored sandboxes.
</ParamField>

<ParamField path="--status" type="string">
  Show only sandboxes in one state. Use one of the states printed by `smolvm sandbox list --all`.
</ParamField>

<ParamField path="--preset" type="string">
  Show only sandboxes created by this preset, such as `openclaw` or `codex`. You can combine this with `--all` or `--status`.
</ParamField>

<ParamField path="--json" type="flag">
  Print a JSON envelope instead of a table. Each sandbox includes its stored `preset`, and `filters` includes the active `preset` filter.
</ParamField>

<Note>
  Use either `--all` or `--status`, not both.
</Note>
