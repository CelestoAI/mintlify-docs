---
title: "smolvm create"
description: "Create an SSH-ready VM and leave it running"
---

## Synopsis

```bash  theme={null}
smolvm create [--name <name>] [OPTIONS]
```

## Description

The `create` command spins up a new VM, waits for it to be SSH-ready, and leaves it running. You can give it a name or let SmolVM generate one automatically. Use `smolvm ssh` to connect to the VM afterwards.

## Options

<ParamField path="--name" type="string">
  A unique identifier for the VM. If you skip this flag, SmolVM auto-generates a name like `vm-a1b2c3d4`. Use this name to reference the VM in other commands like `smolvm ssh` and `smolvm env`.
</ParamField>

<ParamField path="--memory-mib" type="integer" default="512">
  Guest memory in MiB.
</ParamField>

<ParamField path="--disk-size-mib" type="integer" default="512">
  Root filesystem size in MiB.
</ParamField>

<ParamField path="--backend" type="string" default="auto">
  Backend override. Choices: `auto`, `firecracker`, `qemu`. The `auto` option selects the best backend for your platform.
</ParamField>

<ParamField path="--boot-timeout" type="float" default="30">
  Seconds to wait for VM boot and SSH readiness.
</ParamField>

## Examples

### Create a VM with an auto-generated name

```bash  theme={null}
smolvm create
```

SmolVM picks a unique name for you (for example, `vm-a1b2c3d4`) and prints it after the VM is ready. You can then use that name with `smolvm ssh` and other commands.

**Example output:**

```
Created VM 'vm-a1b2c3d4'.
  Backend: firecracker
  IP address: 172.16.0.2
  SSH port: -
  Next: smolvm ssh vm-a1b2c3d4
```

### Create a VM with a custom name

```bash  theme={null}
smolvm create --name my-agent
```

**Example output:**

```
Created VM 'my-agent'.
  Backend: firecracker
  IP address: 172.16.0.2
  SSH port: 2222
  Next: smolvm ssh my-agent
```

### Create a VM with more resources

```bash  theme={null}
smolvm create --name heavy-workload --memory-mib 2048 --disk-size-mib 4096
```

### Specify a backend

```bash  theme={null}
smolvm create --name dev-env --backend qemu
```

### Increase boot timeout for slower systems

```bash  theme={null}
smolvm create --boot-timeout 60
```

## What happens during create

1. SmolVM configures a new VM with the specified settings (or defaults)
2. If you did not provide `--name`, SmolVM generates a unique identifier
3. The VM process starts with the selected backend
4. SmolVM waits for the VM to boot and become SSH-ready
5. Once ready, the VM stays running in the background

After creation, you can connect with `smolvm ssh <name>` or use the Python SDK with `SmolVM.from_id("<name>")`.

## Exit codes

| Code | Description                                        |
| ---- | -------------------------------------------------- |
| `0`  | Success - VM created and SSH-ready                 |
| `1`  | Error - VM creation or boot failed                 |
