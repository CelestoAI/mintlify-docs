---
title: "smolvm stop"
description: "Stop a running VM and release its resources"
---

## Synopsis

```bash  theme={null}
smolvm stop <vm_id>
```

## Description

The `stop` command shuts down a running VM and releases its resources (TAP device, network rules, process). The VM state is removed, so you cannot restart it after stopping — use [snapshots](/smolvm/cli/snapshot) if you need to save and restore state.

## Arguments

<ParamField path="vm_id" type="string" required>
  The identifier of the VM to stop. This is the name you provided (or that was auto-generated) when creating the VM with `smolvm create`.
</ParamField>

## Examples

### Stop a VM by name

```bash  theme={null}
smolvm stop my-sandbox
```

### Create, use, and stop a VM

```bash  theme={null}
smolvm create --name dev-env
smolvm ssh dev-env
# ... work inside the VM ...
smolvm stop dev-env
```

## What happens during stop

1. SmolVM sends a shutdown signal to the VM process
2. The TAP network device and NAT rules are removed
3. The VM state is cleaned up from the local database
4. Temporary disk images are deleted

## Exit codes

| Code | Description                      |
| ---- | -------------------------------- |
| `0`  | Success — VM stopped and cleaned up |
| `1`  | Error — VM not found or stop failed |
