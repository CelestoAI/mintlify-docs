The SmolVM CLI lets you create, manage, and connect to lightweight virtual machines from your terminal. It covers the full VM lifecycle — from creating a sandbox to cleaning up resources when you're done.

## Installation

Install SmolVM via pip:

```bash
pip install smolvm
```

For dashboard support, install with the `dashboard` extra:

```bash
pip install 'smolvm[dashboard]'
```

## Available commands

| Command          | Description                                   |
| ---------------- | --------------------------------------------- |
| `smolvm create`  | Create a named SSH-ready VM                   |
| `smolvm list`    | List VMs and their status                     |
| `smolvm ssh`     | SSH into a VM (auto-starts if needed)         |
| `smolvm env`     | Manage environment variables on a running VM  |
| `smolvm cleanup` | Clean stale SmolVM resources and VMs          |
| `smolvm doctor`  | Run host diagnostics for the selected backend |
| `smolvm ui`      | Start the SmolVM dashboard UI server          |

## JSON output for automation

Most commands support a `--json` flag that switches from the default Rich (human-friendly) output to a structured JSON envelope. This is useful when you're building scripts, CI pipelines, or integrating SmolVM with AI agents and LLMs.

Every JSON response follows the same structure:

```json
{
  "ok": true,
  "command": "list",
  "exit_code": 0,
  "data": { ... },
  "error": null
}
```

| Field       | Type              | Description                                      |
| ----------- | ----------------- | ------------------------------------------------ |
| `ok`        | boolean           | `true` when the command succeeded                |
| `command`   | string            | The command that produced this output             |
| `exit_code` | integer           | Process exit code (`0` = success)                |
| `data`      | object or null    | Command-specific payload on success              |
| `error`     | object or null    | Error details on failure (`message` and `type`)  |

Commands that support `--json`: `create`, `list`, `cleanup`, `doctor`, `env set`, `env unset`, `env list`.

## Getting help

Display help for the main command:

```bash
smolvm --help
```

Display help for a specific subcommand:

```bash
smolvm create --help
smolvm list --help
smolvm ssh --help
```

## Script aliases

The following script alias is also available:

* `smolvm-cleanup`: Equivalent to `smolvm cleanup` (standalone cleanup command)
