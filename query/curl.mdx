## cURL Example

Here's how to query your Agentor deployment using cURL:

```bash
curl -X 'POST' \
  'http://localhost:8000/chat' \
  -H 'accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
  "input": "What is the weather in London?"
}'
```

## For Deployed Apps

When your app is deployed to Celesto, use the production URL:

```bash
curl -X 'POST' \
  'https://api.celesto.ai/v1/deploy/apps/d2cdaacb-ee7e-424c-a7e5-42fc260a91d6/chat' \
  -H 'accept: application/json' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
  "input": "What is the weather in London?"
}'
```

## Parameters

- **URL**: The endpoint URL for your deployed app
- **Authorization**: Your Celesto API key (required for production)
- **input**: The query string you want to send to your agent

## Response

The API will return a JSON response with the agent's reply to your query.
